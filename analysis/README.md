# 血液细胞差异与 L1000 扰动谱：Lasso 分析

本目录包含四部分工作：数据质控、探索性分析、Lasso 回归、候选扰动与转录因子比较。具体结果见 `REPORT.md`；执行记录见 `WORK_LOG.md`。

## 重现

从仓库根目录运行（需要 Python 3.11+，建议独立虚拟环境）：

```bash
git lfs install
git lfs pull
python -m pip install -r analysis/requirements.txt
python analysis/run_analysis.py --data .
python analysis/finalize_results.py --data .
```

运行会覆盖本目录的结果文件。原始数据不会被修改。`L1000 MCF7_OE gene expression.h5` 必须为真正的 HDF5 文件，不能只是 LFS 文本指针。

## 分析规则

- 基因名称转为字符串并去除首尾空白，重复基因保留原文件第一行。保留原始大小写；不在无映射证据时强制改名。基因符号的形式和精确交集可以检查，但没有声明所有符号已通过最新版 HGNC 别名校正。
- 两套数据按共同基因严格同序对齐。零表达保留；它不是缺失值。零方差扰动剔除（若存在）。没有利用目标细胞差异筛选建模基因。
- 血液矩阵来源的完整归一化流程未知。主分析使用文件现有尺度，不声称它是原始计数或确定的 log 表达量。不额外强行取对数；单独比较 `log1p` 敏感性模型。
- L1000 有负值，按提供的有符号特征使用，禁止 log1p。HDF5 仅提供基因、扰动和矩阵，不能仅凭范围确定其具体标准化方法、处理时间或剂量。
- 热图：全血液矩阵上方差最高的 60 个基因，逐基因跨细胞 z 分数，Ward/欧氏距离聚类。PCA 与 5 类聚类：方差最高的 2,000 个基因，同样 z 分数；5 类仅用于探索展示。细胞相关性使用全部去重血液基因的 Spearman 相关系数。
- 对除 HSC 外全部 21 种细胞分别建模：`y_g = target_g - HSC_g`，`X_gj = L1000[g,j]`。未对血液基因跨细胞 z 分数后再作差，避免改变主响应的基因权重。
- 全体共同基因按固定种子 42 分成 80% 训练、20% 测试。每个训练折独立计算扰动列均值/标准差以及响应均值/标准差。模型有截距。随机坐标下降种子 42，容差 1e-4，最多 30,000 次迭代，收敛诊断单独保存。
- 训练集内 3 折交叉验证（种子 43），搜索 24 个相对正则化强度，范围 `alpha/alpha_max=1..0.01`；`alpha_max=max(abs(X.T@y))/n` 在各训练折独立计算。按最小平均验证 MSE 的 1 标准误规则选更稀疏模型。CV 标准误只用于调参启发式，不作为置信区间。
- 训练集调参后在整个训练集重拟合并固定，用未参与调参的测试基因评价。测试指标：R²、RMSE、Pearson、Spearman；基线为训练响应均值。主结果候选也来自此训练集模型，不使用测试集重拟合。
- 候选按标准化响应及扰动列后的系数绝对值排序，符号单独保留。原始响应单位系数另存。全体扰动入模后用 TF 资源标注，并非把所有扰动误称为 TF。
- TF 名单：`human_tfs.txt`，来自 https://raw.githubusercontent.com/phbradley/conga/173a414606cd5935298393daf4411fb2b13fed8d/conga/data/Lambert_et_al_PMID_29425488_TF_names_v_1.01.txt 。下载快照和 SHA256 已保存。采用 Lambert et al., Cell 2018 (PMID 29425488) 的 1,639 个人类 TF 名单 v1.01，精确匹配基因符号；不将广义调控因子全部称为 TF。
- 稳定性：5 次各抽取 80% 训练基因，固定已选的相对 alpha，重拟合；保存入选频率和相同符号频率。次数较少，只作初步稳定性筛查，不是正式稳定性选择的错误率控制。
- 跨细胞比较：每个模型绝对系数最大的前 10 个非零 TF 集合，计算交集及 Jaccard。Jaccard 不反映符号差异，因此另存带符号的完整系数。
- 代表性 TF：优先从正系数、正训练边际相关、重抽样入选频率至少 0.6 的 TF 中选择系数最大的；若无则退回正系数 TF，再退回所有入选 TF。代表图展示测试基因上的边际相关，但并不使用该相关选候选。
- `log1p` 敏感性分析复用基因划分和相对 alpha，没有重新调参。不同响应尺度的 R² 不宜直接解释为同一任务的改善。
- 六个代表谱系另做一次训练响应打乱的对照，保留测试响应不变、固定相对 alpha；这是示意性负对照，未作完整置换检验或计算 p 值。

## 解释边界

细胞类型列是汇总表达谱，没有供体/细胞级生物学重复。基因作为回归观测，测试评价的是同一批细胞谱上留出基因的表达差异重建，并不代表新供体、新细胞或实际重编程的预测能力。基因间相关会让随机基因划分偏乐观，仍需独立数据或基因模块划分验证。

数据是 11,940 左右基因对应 2,717 个扰动的多特征稀疏回归；本次并非严格的 p>n 场景。Lasso 仍适合做稀疏模式匹配，但相关扰动之间可能互相替代。正系数表示联合线性重建中的同向权重；负系数表示反向权重，不能直接等同于敲除或抑制效果。

MCF7 是乳腺癌细胞背景，结果不证明扰动在血液细胞中有同样作用。候选排序是计算假说而非因果结论。myeloid dendritic cell 的高零比例需要特别审慎解释，不能将其预测结果当作高质量生物学证据。所有目标共享 HSC 基线，TF 重叠也可能来自共同参照而非特异的谱系联系。
